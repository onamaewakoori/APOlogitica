# APOlogitica
APO de Fundamentos de Programação para Internet
Sistema web para cadastrar produtos, endereços e transportadores, gerar fretes e baixar o relatório diário em PDF.

Feito com HTML, CSS, JavaScript (Bootstrap), PHP, MySQL e Dompdf.

**Requisito: MySQL do XAMPP ligado.** O banco é criado automaticamente no primeiro acesso.

## Como rodar

1. Copie a pasta `apologistica` para `C:\xampp\htdocs\`.
2. Inicie o Apache e o MySQL no XAMPP.
3. Na pasta do projeto, rode `composer require dompdf/dompdf`.
4. Acesse http://localhost/apologistica/
